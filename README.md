# Formroom 界面资料室

Formroom 是一间开放的界面设计资料室，收录 12 个原创产品概念、36 屏交互样张和 3 篇设计笔记。网站包含即时搜索、平台及设计模式筛选、逐屏链接、可操作的预览，以及保存在当前浏览器中的收藏夹。

## 使用

- 线上地址：[Formroom](https://yunnre060214-sudo.github.io/Design/)
- 本地开发：运行 `python -m http.server 8000`，打开 `http://localhost:8000/`。
- 验证和构建：使用 Node.js 18 或更高版本运行 `npm run build`，静态产物位于 `dist/`。
- GitHub Pages：发布源设为 `main` 分支的根目录。项目采用原生 HTML、CSS 和 ES 模块，GitHub Pages 可直接发布仓库根目录中的站点源文件。
- 数据与设计笔记位于 `catalog.js`，预览组件位于 `screens.js`，图像和签名位于 `assets/`。

案例是为了比较设计决策而创作的交互样张。页面中的价格、指标和产品名称均服务于这些示例。
